About▼

Full Solar System — 8 planets + Ceres (dwarf), asteroid belt, and 31 major moons propagated from full Keplerian elements (a, e, i, Ω, ω, M₀ at J2000) referred to each parent's equator. A logarithmic scale keeps everything visible at once.

Jupiter's four Galilean moons run inside a live Yoshida-4 symplectic N-body integrator so the Laplace 1:2:4 mean-motion resonance and Io's forced eccentricity emerge from pairwise gravity (no analytic forcing).

Triton (Neptune) and Phoebe (Saturn) are retrograde; Nereid traces the most eccentric large-moon orbit in the system (e ≈ 0.75). Solar wind Parker spiral active. Click any body or moon to track it.

Near-Earth objects: every catalogued NEO (asteroids, near-Earth comets, the interstellar visitors) is propagated two-body from JPL SBDB osculating elements in a Web Worker, in the ecliptic of date. Inside 20 lunar distances an object moves to an Earth-anchored frame drawn on the Moon's own compression (the 1 LD ring passes through the drawn Moon). Close approaches are JPL's integrated CAD table, the impact monitor is Sentry, fireballs are US Government sensor reports, and meteor showers are IAU/IMO stream data keyed to solar longitude.

Data Sources & References

Ephemeris: Bretagnon & Francou (1988) VSOP87D · Meeus (1998) "Astronomical Algorithms" 2nd ed. · Standish (1992) JPL secular corrections · NASA JPL Horizons REST API (when available)

Space Weather: NOAA SWPC DSCOVR/ACE rtsw_wind_1m + rtsw_mag_1m · GOES X-ray 1-day · Planetary Kp 1-min · NASA DONKI CME/Flares/SEP

Planet Data: NASA Planetary Fact Sheets (rotation, obliquity, radii) · Murray & Dermott (1999) "Solar System Dynamics" (moon orbits) · IAU/IAG 2015 report (pole orientations)

Small Bodies: NASA/JPL Solar System Dynamics — SBDB Query API (osculating elements, J2000 ecliptic) · Close-Approach Data API · Sentry impact monitor · Fireball API (US Government sensors) · IAU Meteor Data Center / IMO shower list · Two-body propagation on-device (js/neo-orbits.js) with the IAU 1976 general-precession rotation into the ecliptic of date; positions drift from JPL's integrated orbits at ~arcminutes per year and faster across planetary encounters.

Accuracy Notes: Planet longitudes accurate to <0.3° for 1800–2200 AD. Earth VSOP87D <1″. Secular precession rates are linear approximations — over millennia, mutual planetary perturbations (especially Jupiter-Saturn great inequality) cause additional drift. Moon orbital elements are mean Keplerian — Laplace resonance perturbations not modeled (~0.5°/yr drift for Io).
